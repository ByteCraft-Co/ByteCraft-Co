# ByteCraft

Software developer focused on building reliable, maintainable, and performance-conscious software across systems, backend, frontend, tooling, and automation.

I work with a broad technical stack and focus on writing clean code, designing practical systems, improving developer workflows, and building projects that are structured to scale.

## Areas of Interest

- Systems programming
- Backend engineering
- Full-stack development
- Developer tooling
- Automation and CI/CD
- Databases and infrastructure
- Performance, reliability, and maintainability
