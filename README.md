## Main Project

### MIDORI
An LLVM-backed, safe-by-default programming language focused on clarity, correctness, and predictable performance.

Current scope includes:
- Compiler pipeline (lexer, parser, type checker, MIR, borrow-checker MVP)
- CLI toolchain (`build`, `run`, `test`, `fmt`, `repl`)
- LLVM-based native compilation
- Documentation, examples, and CI-based quality checks
- VS Code extension scaffold for `.mdr` language support

## Engineering Standards

- Clean architecture and explicit interfaces
- Test-first mindset with CI-driven quality gates
- Measurable reliability (logging, metrics, tracing)
- Clear documentation for users and contributors
- Backward-compatible evolution when possible

## Philosophy

I prefer simple, robust solutions over fragile complexity.  
Readable code beats clever code.  
Ship, measure, improve, document.
